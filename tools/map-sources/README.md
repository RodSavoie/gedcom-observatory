# Sources for the map in "Where They Lived"

`placenames-canada.csv`: 10,676 Canadian places (cities, villages, hamlets, First Nations communities) with English and
French names, province and coordinates. From "Geolocated placenames in Canada" (Natural Resources Canada, Canadian
Geographical Names Database, and Crown-Indigenous Relations and Northern Affairs Canada), Open Government Licence –
Canada, as packaged in the R package loon.data (github.com/great-northern-diver/loon.data, data/placenamesCanada.rda).

The other sources are npm packages and a Natural Earth file; see the top of `../build-map-data.js`.
